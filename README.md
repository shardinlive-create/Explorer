# 🌊 Мой Проводник (My Explorer)

**Современный файловый менеджер для Windows, написанный на чистом Python + Tkinter.**
Весь проект — **один файл** `my_explorer.py`, без сторонних библиотек. Две панели как в
Total Commander, вкладки как в браузере, умный поиск, плавные анимации и сборка в `.exe`.

## ✨ Почему это круто

-  **Один файл** — никаких зависимостей, установок и настроек. Скачал → запустил.
-  **Современный голубой дизайн** со скруглёнными кнопками и плавными анимациями.
-  **Две панели** (как в Total Commander) с переключением в **одну панель** (как в обычном Проводнике).
-  **Безопасное удаление** — файлы уходят в Корзину, а не исчезают навсегда.
-  **Фоновые операции** — размеры папок и глубокий поиск считаются в отдельных потоках, интерфейс не тормозит.

---

## 🚀 Возможности

| Категория | Функции |
|---|---|
| **Навигация** | Две панели / одна панель, вкладки, история «Назад/Вверх», быстрые ссылки, диски |
| **Поиск** | Живой фильтр по имени + глубокий поиск по подпапкам (галочка) |
| **Файлы** | Копировать / вырезать / вставить, удалить в корзину, переименовать (F2), создать папку и txt |
| **Массовые операции** | Групповое переименование (номер, дата, замена текста) с предпросмотром |
| **Анализ** | Автоматический размер папок, поиск дубликатов по MD5, свойства файла |
| **Архивы** | Создание и распаковка ZIP |
| **Прочее** | Иконки по типу файла, сортировка по колонкам, скрытые файлы, «Открыть в Блокноте», командная строка в папке, режим администратора |

##  Требования

- Windows 10 / 11
- Python **3.8+**
- Сторонние библиотеки **не нужны** (только стандартная библиотека)

---

##  Быстрый старт

```bash
# 1. Склонируй или скачай репозиторий
git clone https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПОЗИТОРИЙ.git
cd ТВОЙ_РЕПОЗИТОРИЙ

# 2. Запусти
python my_explorer.py
```

> При установке Python обязательно поставь галочку **Add Python to PATH**.

---

##  Горячие клавиши

| Клавиши | Действие | | Клавиши | Действие |
|---|---|---|---|---|
| `Ctrl+T` | Новая вкладка | | `F2` | Переименовать |
| `Ctrl+W` | Закрыть вкладку | | `F4` | Открыть в Блокноте |
| `Ctrl+P` | 1 / 2 панели | | `F5` | Обновить |
| `Ctrl+N` | Новая папка | | `Delete` | Удалить в корзину |
| `Ctrl+X/C/V` | Вырезать / копировать / вставить | | `Alt+Enter` | Свойства |
| `Ctrl+A` | Выделить всё | | `Ctrl+Shift+C` | Копировать путь |

##  Сборка в .exe (чтобы работало без Python)

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name MyExplorer my_explorer.py
```

Готовый файл появится в `dist/MyExplorer.exe` — его можно запускать на любом Windows-ПК
без установленного Python.

##  Безопасность

- Удаление по умолчанию идёт **в Корзину** (восстановимо).
- Режим администратора включается вручную кнопкой «Админ» и нужен только для чтения защищённых системных папок.
- Программа ничего не отправляет в интернет и работает полностью локально.
